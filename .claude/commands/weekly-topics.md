# /weekly-topics — 이번 주 주제 후보 뽑기

## ⛔ 이 커맨드는 한 턴 안에서 끝까지 실행한다. 중간에 멈추거나 미루지 않는다.

---

### STEP 1. 날짜 확인 (필수, 건너뛰지 않는다)

```bash
date "+%Y-%m-%d %A"
```

응답 **첫 줄**에 `오늘은 YYYY년 MM월 DD일 O요일이다` 를 출력한다.
이후 모든 파일명의 날짜는 이 결과를 쓴다. 추측 금지.

---

### STEP 2. topic-scout 실행

`topic-scout` 서브에이전트를 실행한다.
(`.claude/agents/topic-scout.md` 의 사양을 그대로 따른다.
 세션에 서브에이전트가 등록되어 있지 않으면 general-purpose 에이전트에
 topic-scout.md 전문을 프롬프트로 넣어 실행한다. 조사량이 많으므로
 검색어 그룹을 나눠 병렬로 여러 에이전트를 띄워도 된다.)

**요구사항**
- 부동산 블로그·커뮤니티 글 **50개 이상** 조사 (하한선)
- 검색어 **8가지 이상** 변주
- 결과를 `research/YYYY-MM-DD-topics.md` 에 저장
- 조사한 글의 **실제 개수**를 명시 (부풀리지 않는다)

---

### STEP 3. 주제 후보 3개 화면 출력

`research/YYYY-MM-DD-topics.md` 를 읽고, 후보 3개를 **번호와 함께** 화면에 출력한다.

출력 형식:

```
오늘은 YYYY년 MM월 DD일 O요일이다.

📊 조사 완료 — 블로그·커뮤니티 글 N개 분석
   검색어 N종 / 저장: research/YYYY-MM-DD-topics.md

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
1️⃣  {주제명}                              [난이도: 하/중]
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
왜 지금  : ...
소제목   : ① ... ② ... ③ ... ④ ... ⑤ ...
차별점   : ...

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
2️⃣  ...
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
3️⃣  ...
```

---

### STEP 4. 알림 발송

```bash
bash scripts/notify.sh "[부동산 블로그] MM/DD 주제 후보 3개 준비 완료" "번호를 골라줘."
```

---

### STEP 5. 대기 안내

마지막 줄에 아래를 출력하고 **사용자 응답을 기다린다.**

```
👉 1, 2, 3 중 번호를 입력하면 바로 글 작성에 들어간다.
   (번호만 입력해도 되고, /weekly-write 2 처럼 입력해도 된다)
```

**여기가 이 하니스에서 사용자에게 질문하는 유일한 지점이다.**
다른 어떤 것도 되묻지 않는다.

---

### STEP 6. STATUS.md 갱신

`STATUS.md` 의 "현재 상태" 섹션을 아래로 갱신한다.

```markdown
## 현재 상태
- 마지막 실행: YYYY-MM-DD (O요일) /weekly-topics
- 조사 글 수: N개
- 주제 후보: research/YYYY-MM-DD-topics.md
- 대기 중: 사용자 번호 선택 (1/2/3)
```
