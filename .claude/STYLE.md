# STYLE.md — 블로그 주인의 어투 규범

> 발행본 3편을 정독해 뽑아낸 규범이다. 추측이 아니라 **실제 발행된 문장에서 역추출**한 것이다.
> 분석 대상: 비교평가 1편(224415160988) / 비교평가 3편(224434380543) / 상급지 편(224412555824)
> 갱신일: 2026-10-16

`writer`와 `novelist` 에이전트는 집필 전에 **이 파일을 반드시 읽는다.**

---

## 1. 기본 어미 — `~이다` 체 + 겸양

`~이다` 체를 쓰되 **독자를 높이는 겸양 표현을 섞는다.**
이 표현들은 `~다`로 끝나므로 절대 규칙 4번에 걸리지 않는다.

| 쓴다 | 쓰지 않는다 |
|---|---|
| 설명을 **드렸다** | 설명했습니다 |
| 말씀**드린** 대로 | 말씀한 대로 |
| 읽고 오시기를 **바란다** | 읽어 보세요 |
| ~하시는 **분들이라면** | ~하는 사람이라면 |
| ~을 **권한다** / **추천드린다** | ~하세요 |
| 답변하실 것으로 **예상한다** | 답변하실 겁니다 |
| 도움이 되었기를 **바란다** | 도움이 되셨나요 |

**1인칭을 숨기지 않는다.** "나는 ~라고 생각한다", "개인적으로는 ~를 추천하는데", "나에게는 ~할 능력이 없다".

## 2. 문장 리듬 — 짧은 자문(自問)으로 끊어 간다

주인의 글에서 가장 두드러지는 장치다. **긴 설명 뒤에 한 줄짜리 질문을 던지고 답한다.**

```
왜 그럴까.
이게 무슨 뜻일까.
그렇다면, 상품성이 비슷한 단지들은 어떻게 묶을 수 있을까?
그런데 왜 "보통의 경우"라는 단서가 붙었을까.
정말로 이 질문이 그렇게 쉬운 질문일까.
```

- 자문은 **독립된 한 줄**로 둔다. 문단에 섞지 않는다.
- 자문 뒤에는 **반드시 바로 답**이 온다. 질문만 던지고 넘어가지 않는다.
- 한 글에 **3~5개**가 적당하다. 너무 많으면 산만해진다.

그리고 긴 문단 뒤에는 **짧은 단정 한 줄**로 못을 박는다.

```
그래서 기본적으로는 입지다.
오래 들고 있을수록 건물은 더 많이 낡는다. 그러니 더더욱 입지다.
가격표는 같아도 그 안의 구성은 다르다.
```

연결어로는 **"다시 말해서,"**, **"그도 그럴 것이,"**, **"그러면서 자연스레 알게 된 부분들이 있다."** 를 쓴다.

## 3. 따옴표로 개념과 질문을 집는다

볼드체 대신 **큰따옴표**로 강조한다. 네이버 발행본에 볼드가 거의 없다.

```
"급지"란 이 두 요소가 어우러져 정해진다.
"같은 돈이면 이 동네를 사지"의 좋은 기준이 되기도 한다.
그 폭이 붙을 "수도" 있다. 그럴 "가능성"이 있으니
나는 "보통의 경우" 입지라고 대답할 것이다.
그냥 "부동산은 입지"라고만 외웠기 때문이다.
```

- 핵심 용어, 흔한 오해, **유보를 나타내는 낱말 하나**(수도·가능성·보통의 경우)에 씌운다
- 마크다운 볼드(`**`)는 **한 글에 세 군데 이하**로 아낀다

---

## 4. 유보와 선 긋기 — 단정하지 않는다

주인은 **자기 예측력의 한계를 먼저 밝힌다.** 이게 글의 신뢰를 만든다.

```
나에게는 앞으로 아파트 시장이 오를지 내릴지 예측할 수 있는 능력이 없다.
다만, ~한다면 ~할 "수도" 있다. 그럴 "가능성"이 있으니 이에 대비하자는 것이다.
```

그리고 **본론에 들어가기 전에 아닌 것부터 지운다.**

```
앞으로 가격이 폭락할 것이니 폭락을 대비하자는 말이 아니다.
가격은 무조건 오를 것이니 무리해서라도 상급지를 사두라는 말도 아니다.
다만, ~
```

→ `아니다 / 아니다 / 다만` 3단 구성이다. 오해를 미리 막고 논지를 좁힌다.
→ **주장이 세질 자리마다 이 장치를 쓴다.**

## 5. 수치 대신 가상 예시를 쓴다  ★가장 중요

주인은 조사 수치를 **거의 전부 덜어내고, 대신 머릿속에 그려지는 숫자 예시를 만든다.**

실제로 저장소 초안의 "땅값 비싼 자리는 건축비를 3~4년에 회수, 싼 자리는 10년 이상"을
발행본에서는 이렇게 바꿨다.

```
예를 들어, 아래의 두 단지를 비교해 보자. 두 아파트의 가격은 10억으로 동일하다.
- 덜 좋은 입지의 신축 아파트 A: 땅 값 7억 + 건물 값 3억
- 더 좋은 입지의 구축 아파트 B: 땅 값 8억 + 건물 값 2억
```

- **기관명을 본문에 적지 않는다.** 꼭 필요하면 "한 조사에 따르면" 정도다
- 통계를 꼭 쓸 자리면 **괄호 안에 한 번만** 넣는다
  → `(통계 상으로는 평균 보유기간은 5년이고, 실거주인 경우 평균 거주기간이 11년이라고 한다)`
- 퍼센트, 소수점, %p, 상관계수, 표본 수는 **본문에 쓰지 않는다**
- 조사한 수치는 버리는 게 아니다. **notes 파일에 남겨 둔다**

## 6. 절 구분은 구분선으로만 한다

```
--------------------
```

- 하이픈 20개짜리 구분선으로 절을 나눈다
- `##`, `###` 같은 마크다운 머리글을 쓰지 않는다
- 소제목이 필요하면 **문장형 평문**으로 쓴다
  → `1. 건물은 시간이 지날수록 낡지만, 땅의 가치는 낡지 않는다.`
  → `① 2~3년만 짧게 보유할 계획인 경우`
- 번호는 `1. 2. 3.` 또는 `① ② ③`을 쓴다

## 7. 지난 글 링크 형식

```
혹시 앞의 글들을 아직 읽어보지 못하신 분들이라면, 더 나은 이해를 위해
아래 순서로 이전 글들을 먼저 읽고 오시기를 바란다.

1. 입지 평가 방법
https://m.blog.naver.com/cha_jang/224389395953

2. 상품성 평가 방법
https://m.blog.naver.com/cha_jang/224404759787
```

- 안내 문장 → 번호 + 글 설명 → **벌거벗은 URL** 순서다
- 마크다운 링크(`[제목](url)`)를 쓰지 않는다. 네이버가 미리보기 카드를 붙여 준다
- 주소는 `research/blog-post-urls.md`에서 가져온다

## 8. 마무리 — 도입과 호응시킨다  ★집중력의 비결

주인의 글은 **도입의 장면을 마무리에서 다시 불러온다.** 수미상관이다.

상급지 편의 도입과 마무리를 보면 분명하다.

| 도입 | 마무리 |
|---|---|
| "2022년 겨울, ~ 나는 15억짜리 집을 보러 다녔다." | "2022년 겨울, 주변에서는 내가 당장 사지도 못할 집을 보러 다닌다고 걱정했다." |
| "값을 치를 돈은 없어도, 값을 알아보는 눈은 먼저 가질 수 있었기 때문이었다." | "그해 겨울 걸어 둔 동네들의 기억과 기록은 지금도 내게 비교의 기준으로 남아 있다." |

**마무리에서 도입의 시점·장면·낱말을 한 번 되짚는다.** 그러면 글이 한 덩어리로 닫힌다.

마무리 뒤에 사인오프를 붙일 수 있다. 쓰거나 안 쓰거나 둘 다 주인의 발행본에 있다.

```
오늘의 글도 부동산을 공부하시는 분들에게 짧은 식견이지만 조금이라도 도움이 되는 글이었기를 바란다.
```

그리고 **맨 마지막 줄은 고정 맺음 문구다** (절대 규칙 10번).

## 9. 소설 도입의 문체 (novelist 전용)

주인의 도입부는 **담담한 1인칭 과거형 수기**다. 소설적이지만 감정을 과장하지 않는다.

### 쓰는 것

- **시점과 상황을 한 문장으로 세운다**
  → "2022년 겨울, 남들보다 한참 늦어진 공부를 끝내고 사회생활을 시작한 지 1년도 되지 않았을 때였다."
- **행동으로 심정을 보여 준다.** 형용사로 설명하지 않는다
  → "퇴근 후엔 집과 반대 방향으로 가는 지하철을 탔다."
  → "경비실 앞을 지날 때만큼은 여기 사는 사람인 척 얌전해졌다."
- **사물 한 컷을 넣는다.** 장면이 박힌다
  → "겨울이라 미끄럼틀은 비어 있었고, 그네 쇠사슬이 바람에 저 혼자 흔들렸다."
- **숫자는 소품으로만 쓴다**
  → "통장에 찍혀 있는 숫자는 3000만원이 채 되지 않았지만"
  → "12억, 13억. 15억."
- **감각을 나열해 대비를 만든다**
  → "외벽은 얼룩져 있고, 주차장은 좁아 차들이 이중으로 서 있고, 복도 조명은 어두웠다."
- **마지막 줄은 본문으로 넘어가는 질문이나 깨달음이다**
  → "왜 저 오래된 집이 더 비쌀까."
  → "값을 치를 돈은 없어도, 값을 알아보는 눈은 먼저 가질 수 있었기 때문이었다."
  → "그리고 현재 결과는 어떻게 되었을까?"

### 쓰지 않는 것

- 감정 형용사 (설레었다, 막막했다, 벅찼다, 뼈저리게)
- 느낌표, 말줄임표 남용
- 비유 과잉 ("마치 ~처럼"을 두 번 이상 쓰지 않는다)
- 교훈을 직접 말하는 문장 (그건 본문이 할 일이다)
- 현재형 서술 (전부 과거형이다)

### 분량

**공백 포함 500자 이내, 한 덩어리로 쓴다.**
문단은 두세 개로 나눠도 되지만 전체가 500자를 넘지 않는다.

## 10. 한눈에 보는 금지 목록

| 금지 | 대신 |
|---|---|
| `## 소제목` 머리글 | `--------------------` 구분선 + 평문 번호 |
| `- [ ]` 체크리스트, "확인할 것", "체크포인트" 절 | 본문 흐름 안에서 풀어 말한다 |

| 기관명·보고서명 본문 표기 | "한 조사에 따르면" |
| 볼드 남용 | 큰따옴표 |
| 마크다운 링크 | 벌거벗은 URL |
| 감정 형용사(소설부) | 행동과 사물 |
| 단정 ("무조건", "반드시 오른다") | "~수도 있다", "~라고 본다", "그럴 가능성이 있다" |
