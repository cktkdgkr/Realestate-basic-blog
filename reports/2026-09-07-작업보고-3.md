## 1. 체크리스트를 2번 자리로 옮겼다

말씀이 맞다. **"내가 산다고 생각하고 봐라"는 관점을 주지만, 현장에 들고 갈 목록은 아니다.**
관점은 관점대로 두고, 걸으면서 볼 것은 목록으로 정리했다.

### 어디에 놓았나

**글 마지막이 아니라 2번 항목 끝에 붙였다.**

읽고 나서 스크롤을 한참 내려야 나오는 목록은 잘 안 본다.
그 이야기를 막 읽은 자리에 목록이 있어야 **바로 갈무리해서 들고 나간다.**

이렇게 이었다.

> 말로 풀어 놓으면 현장에서 놓치기 쉬우니, 걸으면서 볼 것만 따로 정리해 둔다.
> **단지에 갈 때 이 목록만 들고 가면 된다.**

### 무엇을 담았나

**2번에서 다룬 것만 담았다.** 총 15줄이고, 걷는 동선 순서 그대로 4덩어리로 묶었다.

| 묶음 | 항목 |
|---|---|
| **차에서 집까지** | 지하주차장 엘리베이터 직결 여부(버튼 직접 눌러 볼 것) / 안 되는 라인인지 / 주차칸 폭과 이중주차 / 비 오는 날 짐 들고 오는 동선 |
| **동과 동 사이** | 앞 동이 높이의 절반 이상 떨어졌는가 / 낮에도 커튼을 쳐야 할 집인가 / 건폐율 비교 |
| **단지 안 길** | 지상 차량 통행 / 아이·유모차가 다닐 길 / 경사와 단차 / 조경·외벽·분리수거장 관리 상태 |
| **현관 앞** | 복도식인가 계단식인가 / 현관 앞이 사적인 공간인가 / 앞뒤 통풍 |
| **마지막 한 줄** | 1년을 산다면 가장 먼저 불편할 것 같은 게 무엇인가 |

**본문 순서와 목록 순서를 똑같이 맞췄다.** 읽은 순서대로 확인하게 되어 빠뜨리지 않는다.

### 지운 것

마지막의 「임장 30분 상품성 체크리스트」 절을 **통째로 삭제했다.**

거기에는 2번 밖의 항목(세대 판정, 세대수, 커뮤니티 과잉)도 섞여 있었는데,

그래서 지금 글의 체크박스는 **2번 항목 안에 있는 15줄이 전부**다.

## 2. 용어 정리 부분을 없앴다

이 글에는 「상품성이란 무엇인가」 절 안에 용어 풀이가 들어 있었다.

**신축·준신축·구축의 연차 구분, 그리고 신축 프리미엄 설명이었다.**

### 어떻게 처리했나

**버린 게 아니라 필요한 자리로 옮겼다.**

| 있던 것 | 처리 |
|---|---|
| 상품성의 정의 | **도입으로 흡수.** "이때 승부를 가르는 것이 상품성이다" 바로 뒤에 두 줄로 붙였다 |
| 신축 / 준신축 / 구축 연차 구분 | **삭제.** 본문이 이미 "5년 안쪽 새 아파트", "20년 넘은 단지"처럼 쉬운 말을 쓰고 있어 필요가 없었다 |
| 신축 프리미엄 | **4번 항목의 연식 대목으로 이동.** 그 이야기가 실제로 필요해지는 자리다 |
| 마무리의 "준신축" | "더 이상 새 아파트가 아니고"로 **쉬운 말로 갈아 끼웠다** |

신축 프리미엄은 옮겨 놓으니 오히려 논지가 살았다.

> **새 아파트라는 이유로 붙는 웃돈은 분양가에 이미 상당 부분 들어가 있다.**
> 새것이라 오르는 게 아니라, **새것 값을 이미 치르고 들어간다**는 뜻이다.
>
> 실제로 최근 1년 수도권에서는 20년 넘은 단지가 5년 안쪽 새 아파트보다 더 올랐다.

앞에 뚝 떨어져 있을 때는 그냥 용어 설명이었는데,
연식 데이터 바로 앞에 오니 **그 데이터를 해석하는 근거**가 됐다.

### 글 구조가 이렇게 바뀌었다

**이전**: 도입 → 상품성이란 무엇인가(용어) → 실전 4단계 → 체크리스트 → 마무리
**이후**: 도입 → **실전 4단계**(2번 안에 체크리스트) → 마무리

절 하나가 통째로 빠지면서 **본론까지 도달하는 시간이 짧아졌다.**
